Coffee Gozar - نسخه اصلاح مسیر تصاویر

1) ابتدا فایل ZIP را کامل Extract کنید.
2) پوشه Coffee_Gozar_Final را در VS Code باز کنید.
3) فایل index.html را با Live Server اجرا کنید یا آن را در مرورگر باز کنید.

ساختار پروژه به صورت یک‌سطحی است: فایل‌های HTML و CSS کنار پوشه images قرار دارند.
تمام آدرس تصاویر به صورت نسبی (images/...) تنظیم شده‌اند؛ بنابراین به تنظیم خاصی برای پوشه public نیاز نیست.
